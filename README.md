# Starling 🐦

Starling turns one coding goal into a murmuration of open-weight coding agents. It maps your repo, plans
the work into non-overlapping file _lanes_, runs each task in its own git worktree and opencode session,
audits every result with a local model, and merges the passing work onto one integration branch — without
the agents ever stepping on each other. Flock mode spreads the same swarm across laptops on your LAN.

Open source, MIT, open-weight first.
