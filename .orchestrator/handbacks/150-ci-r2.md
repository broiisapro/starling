**Key design decisions:**

- **Aggregator instead of renaming the required check.** Branch protection is keyed on the display name; the tiny `needs`/`if: always()` job keeps `test (ubuntu-latest)` meaningful and cannot be skipped when a half fails.
- **`continue-on-error` on the Playwright suite step, not the job** — a missing Chromium or a broken install must still be red; only snapshot drift is advisory.
- **Docs link check as its own job** so its minutes and failures never attach to the required `lint + typecheck`.
- **`tools/*` glob in the typecheck step** picks up future tool dirs automatically and skips `tools/fully-open` (no tsconfig); only the e2e tsconfig is conditional by design.
- **Nightly is proven by a narrow `pull_request` path** because `workflow_dispatch` does not exist until the workflow is on `main`.
- **PR size counts changed lines, not files**, and slashless ignore patterns match a basename at any depth (`*.jsonl`, `bun.lock`).
- **Only `github.token`/`GITHUB_TOKEN`** — the size job uses `github.token`, so no `secrets.*` reference exists anywhere.
