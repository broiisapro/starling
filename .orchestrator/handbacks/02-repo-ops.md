**Key design decisions:**
- **`qwen3.8:27b-mlx` is the mbp primary, not `qwen3.6:35b-a3b`.** An 18 GB model already leaves only
  ~27% of 32 GB free; a 23 GB model plus 8 sessions would swap. Measured, correct verdict. The 35B
  pull was aborted at ~42%; Epic 28 decides the final auditor model. Reversal is one line in
  `candidates.json`.
- **Issues are never edited by default; `--refresh` is an explicit opt-in.** Issue numbers are API
  surface (`Closes #3`), so body fixes must not churn them.
- **The streaming client was kept and tested rather than reverted.** It built cleanly, and the
  requirement for a mocked-`fetch` suite is what makes it safe: `bun test tools/local-models` runs
  with no network and no model, which is the only kind of test this repo can run on a full laptop.
- **`contract-request.yml` change kept, because the committed version was invalid YAML.** Its
  example text put `": "` inside a plain scalar; GitHub would not have rendered the form. Rephrased
  without the colon (validated with `Bun.YAML.parse` on both versions).
- **Memory lesson recorded as policy, not just notes.** Local models load only for audit/bench epics
  (10, 16, 28) with ≤ 8 agents running; build waves run API-only.
