## Deliverables
1. **Harness `support.ts`.** `fakeGh()` — an `exec`-compatible function you write yourself (read `packages/github/src/testing/fake-gh.ts` for inspiration, don't import it) that keeps in-memory issues/PRs/labels, answers `gh repo view`, `gh issue list/create/edit/comment`, `gh pr list/create/view/edit`, `gh label create`, `git remote get-url origin`, records every argv, and can be told to fail with exit codes and stderr (auth failure, `HTTP 403 … secondary rate limit`, `ENOENT` for a missing `gh`); `tracker(opts)` = `createGitHubTracker({ cwd, repo: 'acme/sky-todo', exec, sleep: async () => {}, settleDelaysMs: [], warn })`; `run()` built from `makeRun`/`makePlan`/`makeTaskRun`; `tempDb()`; `fixtureEvents()` = `importJsonl('fixtures/runs/sky-todo-launch-day.jsonl')`.
2. **`tracker.test.ts` (~12).** `syncPlan(run)` creates one issue per task and returns `Record<taskKey, number>`; a second `syncPlan` creates nothing new (found through `taskMarker(runId, key)`); tasks that already carry `issueNumber` skip the listing; `dryRun: true` performs no mutating `gh` call and `dryRunLog()` lists what it would do; `openTaskPR` returns a URL and, for a task with nothing to review, `undefined` plus a `warn`; `onMerged` comments once; `openFinalPR` body contains every task; no argv element ever goes through a shell (`sh`/`bash -c` never appears) and bodies travel by file/stdin, not argv; auth failure → `GitHubError` with `githubCode: 'GH_AUTH'` (`isGitHubError(err, 'GH_AUTH')`), missing binary → `GH_MISSING`, bad repo → `GH_REPO`; a secondary rate limit is retried with `backoffMs` and then succeeds.
3. **`render.test.ts` (~8).** `renderTaskIssue`/`renderTaskPRBody`/`renderFinalPRBody`/`renderMergedComment` contain the marker, escape titles with `|`, backticks and `<!--`; `clampBody` keeps output ≤ `GITHUB_MAX_BODY_CHARS` with `BODY_TRUNCATION_NOTE` and never splits a surrogate pair; `parseGitHubRemote` for `https://github.com/o/r(.git)`, `git@github.com:o/r.git`, `ssh://git@github.com/o/r`, trailing slash, and a non-GitHub host; `isRetryableGhFailure` on the documented texts; `backoffMs` grows and caps at `maxDelayMs`; `parseWorkerHandback`/`stripWorkerHandback` round trip.
4. **`sqlite.test.ts` (~10).** `createSqliteStore(':memory:')` and a temp file: `saveRun`/`getRun` deep-equal round trip (optional fields, unicode, a 300-task plan); `saveRun` twice updates in place (`listRuns` has one entry); `listRuns` most recent first; `events(runId, since)` boundary (`ts === since` included or not, matching the server's `matchesSince` and the doc); `'*'` events stored and retrievable as documented; `appendEvents(batch)` ≡ sequential `appendEvent`; data survives `close()` and reopen; `PRAGMA user_version === STORE_SCHEMA_VERSION`; use after `close()` → `STORE_ERROR` (not a raw SQLite error); `exportJsonl` writes a file `importJsonl` reads back equal.
5. **`jsonl.test.ts` (~8).** `serialiseJsonl([]) === ''`; parse → serialise → parse of the launch-day fixture is a fixed point; CRLF, blank lines and a trailing partial line; a leading UTF-8 BOM (document behaviour); invalid JSON and an unknown `type` on line N → `STORE_ERROR` with `details.line === N` and the source path in the message; `writeJsonl` into a missing directory → `STORE_ERROR`; `importJsonl` of a missing file → `STORE_ERROR`.
6. **`derive.test.ts` (~5).** `deriveRun(fixtureEvents())` equals the `run.finished` payload's run (statuses, keys, metrics); `createRunAccumulator` applied event by event equals `deriveRunState` on the batch; `eventCount`/`lastTs` correct; node list matches `node.joined`/`node.left`; an empty event list → `undefined` run.
7. **`replay.test.ts` — timing on a fake clock (~8).** `createReplayer({ events, bus, clock: new FakeClock(...), speed })`: published gaps equal `min((ts[i]-ts[i-1])/speed, MAX_REPLAY_GAP_MS)`; negative gaps (out-of-order ts) become 0; `speed: Infinity` emits all in one tick; `speed` 0, negative or `NaN` → the documented error; `newRunId` rewrites `runId` everywhere including `payload.run.id` and every `tasks[].runId` (`rewriteEventRunId`), and the documented treatment of `'*'` events; `stop()` mid-replay drops the rest, is idempotent, and `done` resolves; `attachRecorder(bus, store)` persists every published event and its returned function unsubscribes.
