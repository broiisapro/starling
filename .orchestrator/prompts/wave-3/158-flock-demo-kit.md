## Goal
The two-laptop flock is the most impressive moment of the demo and the most fragile: wrong wifi, a firewall prompt, a hub bound to loopback, a version mismatch, a dead opencode. Moksh will run this on demo day with no time to debug. Build the kit that makes it boring: a **preflight** that runs 20–30 checks in one go on each laptop and prints a fix for every failure, a **scripted rehearsal** that walks the loopback scenario with presenter narration, a **printable one-page runbook** that says exactly what to do on which laptop, and a loopback that cannot flake on a machine running 100 agents. Great looks like: on each laptop, `bun tools/flock/preflight.ts` ends with `27 pass · 1 warn · 0 fail — ready for stage`.

## Deliverables
1. **Preflight engine** `tools/flock/preflight.ts` (pure, injectable): `export type CheckStatus = 'pass' | 'warn' | 'fail' | 'skip'`; `export interface PreflightCheck { id: string; group: 'machine' | 'tools' | 'repo' | 'network' | 'hub' | 'perch' | 'demo'; title: string; status: CheckStatus; detail: string; fix?: string }`; `export interface PreflightProbes { exec(argv: string[], opts?: { timeoutMs?: number }): Promise<{ code: number; stdout: string; stderr: string }>; fetch: typeof fetch; networkInterfaces(): ReturnType<typeof import('node:os').networkInterfaces>; portFree(port: number): Promise<boolean>; now(): number; env: Record<string, string | undefined>; freeDiskGb(path: string): Promise<number | undefined>; totalMemGb(): number; platform: NodeJS.Platform }`; `export async function runPreflight(opts: { role: 'hub' | 'perch'; hubUrl?: string; code?: string; hubPort?: number; perchPort?: number; repo?: string }, probes: PreflightProbes): Promise<PreflightReport>`; `formatPreflight(report, { color: boolean }): string`.
2. **At least 22 checks, all in one run**, each with a one-line `fix`: bun 1.4.x; git ≥ `MIN_MERGE_TREE_VERSION` (`parseGitVersion` from `packages/workspace/src/index.ts`); opencode on PATH and its version (never start a session); gh present (warn only); repo is a git repo, clean, `node_modules` present; `fixtures/runs/sky-todo-launch-day.jsonl` present (Plan B replay); `apps/web/dist` built (warn); LAN IPv4 found (`findLanIPv4` from `packages/perch/src/index.ts`); iPhone-hotspot / link-local / guest-network heuristics (info); hub port 7777 and perch port 7778 free on the right role; free disk ≥ 5 GB; RAM; macOS firewall state (`/usr/libexec/ApplicationFirewall/socketfilterfw --getglobalstate`, warn); **perch role:** hub `GET /api/health` reachable, same /24 as the hub, versions match, clock skew from the `Date` header < 5 s, join code format valid and accepted by `GET /api/flock/join`; **hub role:** the hub answers on its **LAN IP**, not only `127.0.0.1` (see the extra rule about SEC-01).
