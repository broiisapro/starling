## Goal
`starling.config.yaml`, `STARLING_*` env vars and the LLM routing profiles decide which model runs where, how many agents launch and where worktrees land. A silently ignored typo or two packages disagreeing on a default is exactly the kind of bug that surfaces on demo day on a fresh laptop. Bug-hunt config loading (`loadConfig`, `StarlingConfigSchema`, `modelFor`), env and profile resolution (`parseProfile`, `applyProfile`, `createLLMFromEnv`, auditor `parseAuditorProfile`/`defaultLlmMode`/`chooseAuditorModel`, planner `discoverOpencodeService`), defaults that are duplicated across packages, path resolution and error messages.
