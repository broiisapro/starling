## Goal
Starling parses untrusted, messy text all day: model JSON, JSONL recordings, git diffs and numstat, merge-tree output, conflict markers, source code for symbols, lane globs and YAML configs. Hand-picked cases miss the weird ones. Write a tiny dependency-free property-testing kit (seeded PRNG, generators, a simple shrinker) and use it to state and check properties of each parser. Great looks like ~40 properties, all deterministic by seed, a `QA_FUZZ_RUNS` knob for long local runs, and every counterexample frozen as a concrete `test.todo` with its seed.

## Deliverables
1. **`prng.ts` + `gen.ts` + `prop.ts` (the kit, ~150 lines).** `mulberry32(seed)`; generators `int(lo,hi)`, `pick(xs)`, `bool`, `string({ alphabet, min, max })` with alphabets for ASCII, path-safe, unicode (combining marks, emoji, RTL, NUL, CRLF), `array(g, …)`, `oneOf`, `record`; `forAll(name, gen, property, { runs = Number(process.env.QA_FUZZ_RUNS ?? 200), seed })` that, on failure, shrinks (shorter strings/arrays, smaller ints, up to 200 steps) and throws a message with the seed and minimal case. Kit tests (~5): same seed gives the same sequence; the shrinker reaches a known minimum; the failure message contains the seed.
2. **`json.test.ts` — model JSON extraction (~5).** From `@starling/llm` (`extractJson`, `stripFences`, read-only import of `packages/llm/src/index.ts`): for any generated JSON value wrapped in random prose, ```json fences, BOM, CRLF and trailing text, extraction returns a deep-equal value; `stripFences` is idempotent; garbage never throws anything but a `StarlingError` (or the documented result type); the planner's `PlanDraftSchema.safeParse` on mutated drafts never throws.
3. **`plan.test.ts` — planner graph and repair (~7).** For random DAG-or-not task sets: `findCycles(buildDepGraph(tasks))` is non-empty iff a Kahn topological sort (written in the test) fails; `validatePlan` never throws on any `PlanSchema`-valid plan; `repairPlan` is idempotent and never introduces a `missing-dep`; `assignTaskKeys` gives unique keys and is deterministic; `dependencyOrder` puts every dependency before its dependant; `canRunConcurrently(a,b) === canRunConcurrently(b,a)`.
4. **`jsonl.test.ts` (~5).** For generated valid events (core factories + random payload strings): `parseJsonl(serialiseJsonl(evts))` deep-equals; corrupting line k → `STORE_ERROR` with `details.line === k`; random bytes never throw a non-`StarlingError`; the web's `parseEventLines` (`apps/web/src/lib/events.ts`) accepts exactly the lines the store accepts, with `skipped` equal to the bad-line count (parity property; differences → todo or open question).
5. **`diff.test.ts` (~7).** `parseNumstat` round trip from generated numstat rows (tabs, spaces, unicode, `-	-` binary); `splitNul`; auditor `splitDiff` on concatenated generated file diffs returns one block per file with paths preserved; `prioritiseDiff(p, { owns, maxChars })` output length ≤ `maxChars` (+ documented marker) and owned files first; workspace `truncatePatch(p, limit)` ≤ limit bytes and valid UTF-8; merger `parseMergeTree` on generated outputs recovers the conflicted file list; `findHunks` on generated files with k inserted conflict blocks finds exactly k.
6. **`symbols.test.ts` (~4).** `extractSymbols(src, lang)` for every language in `SYMBOL_LANGUAGES`: never throws, ≤ `SYMBOL_CAP` results, finds every generated `export function nameN`/`def nameN`/`fn nameN`/`func NameN` line; pathological inputs (50k `a`s, unbalanced brackets, 10k-deep nesting) finish within a generous per-test timeout (catastrophic backtracking guard: report the input that's slow instead of asserting ms).
7. **`glob.test.ts` — lanes (~7).** `normalizeGlobPath` idempotent; `matchesGlob` agrees with an oracle (`new Bun.Glob(pattern).match(path)`) on the supported subset (`*`, `?`, `**`, `[…]`; no braces; ignore the documented directory semantics by only generating patterns whose last segment has a wildcard); **safety property**: if any generated path matches both a glob in A and one in B, `globsOverlap(A, B)` is non-empty (no false negatives, ever); `lanesDisjoint` is symmetric; auditor `checkLane(files, owns)` violations equal `files.filter(f => !matchesAny(f, owns))` minus bookkeeping paths; `globCanNameNewFile` never throws.
8. **`names-config.test.ts` (~5).** `sanitizeBranch`/`sanitizeBranchName` outputs are idempotent and valid refs (batch-check 50 samples with one `git check-ref-format --branch` loop); `normalizeJoinCode`/`verifyJoinCode` round trip; generated YAML-ish objects written to temp files: `loadConfig` returns a config or throws `CONFIG_INVALID`, never another error; `StarlingConfigSchema.parse(defaultConfig)` is a fixed point.
