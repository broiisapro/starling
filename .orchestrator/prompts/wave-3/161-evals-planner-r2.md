## Goal
The planner is Starling's brain: if it splits a goal badly, a hundred birds collide. Epic 48 took the eval from 0.690 to 0.956 on eight cases, but those cases are mostly "add N independent features". Round 2 doubles the set with the goals that actually break planners (cross-cutting refactors, features that fight over the same file, the Python target, too-big and too-small goals), scores the two structural properties that decide parallel speed-up (lane overlap between tasks that can run at the same time, and DAG depth), and adds a **recorded-response mode** that runs the **real** `@starling/planner` (prompt, parse, repair, renumber) against recorded completions with no model. CI and every agent can then catch a planner regression in seconds, offline.
